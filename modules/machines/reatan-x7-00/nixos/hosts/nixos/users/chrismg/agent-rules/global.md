# Global rules

## Council members

When you use the council skill, the council members are these three models,
each at high reasoning effort:

- Claude Opus 5.5 (`claude-opus-5-5`), from Anthropic.
- GPT Sol 6.1 (`gpt-6.1-sol`), from OpenAI.
- Gemini 4 Neon (`gemini-4-neon`), from Google.

Use these members even when a newer model exists. If one of them is not
available, report it instead of substituting another model.
