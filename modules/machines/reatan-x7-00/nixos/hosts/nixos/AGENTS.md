# hosts/nixos

The host `nixos`, the only NixOS system on `reatan-x7-00`. Build it with `sudo nixos-rebuild switch --flake .#nixos`.

## Files

| File | What it does |
| --- | --- |
| `default.nix` | Boot settings: systemd-boot, EFI variables, and the newest kernel. |
| `hardware-configuration.nix` | Hardware settings generated by `nixos-generate-config`. Do not edit. |

## Subdirectories

- [users/](users/AGENTS.md): Home Manager settings for each user.

## Rules

- Add host-specific settings to `default.nix`. Leave `hardware-configuration.nix` as generated.
- If the hardware changes, regenerate `hardware-configuration.nix` and review the diff before you rebuild.

## Keeping this file current

When you change the files in this folder, update this file in the same change. If you add a subdirectory, give it an AGENTS.md and link it under Subdirectories. If you remove one, delete its AGENTS.md and its link. The full rules are in the root `AGENTS.md`.
